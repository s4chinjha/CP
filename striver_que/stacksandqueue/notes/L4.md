# Implement Min Stack

- Only addition is the getMin() function,
- all else are the same.
- We can use a pair<int , int> where 1st stores the currVal and the next keeps track of the min num.


For diff methods:
- Push: we push the val to the currVal and then compare with the second num and update the minVal.
-getMin: we simply get the value of the second num in the pair
- POP: we remove the current pair
- TOP: we simply return the value in the currVal.

The first impl takes:
  T.C. = O(1) and S.C. = O(2*n)

Optimized will take S.C. = O(n)
In this we will use the formula: 2*val - min = newVal if(min > val)


Just keep in mind to use Long Long otherwise everything was correct.
