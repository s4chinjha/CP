We have to find:
The next greater element than the currElement if not found in (i+1 to n-1),then(0 to i-1)

What to use:
We use cicular array.
We visualize that the array has been doubled. and go from curr i to the +n elements and find if
anything is greater than the element.


Brute Force:

We take a nge[n]

  inner loop j = i+1 to i+n-1
    index = j % n
