# Next Greater Element

Monotonic Stack is the stack which is in a specific order.

We have to find this:
Find the next greater element for the currNum & store it in the nge array an then return that array

Brute Force:
we declare nge[n]
We run a loop from i = 0 to n-1
  Inside we run one more loop from j = i+1 to n-1
    We will check if(arr[j] > arr[i]){
      nge[i] = arr[j],break
    }else{
      nge[i] = -1;
    }

return nge

T.C. = O(n**2)
S.C. = O(n)


Optimized Approach:

The thought Process:
[3,4,5,6,7,7,8,9,10]

If i iterate over form the left then i would not know for an element, what the nge is 
for that num on the right.

{Back Traversal}
SO, we iterate from the right, this way we can keep track of what nums are on the right for a num.


PseudoCode:
//My implementation:

we have the array 
nge[n];
we iterate from the back
for(int i  = n-1;i > 0;i--){
  if(st.empty()){
    st.push(arr[i]);
    nge[i] = -1;
  }
  else{
    if(st.top() > arr[i]){
      nge[i] = st.top();
      st.push(arr[i]);
    }
    else{
      while(arr[i] >= st.top() && !st.empty()){
        st.pop();
      }
      
    }
  }
}

//Optimized Impl

for(int i  = n-1;i > 0;i--){
  //remove all the smaller values first
  while(arr[i] >= st.top() && !st.empty()){
    st.pop();
  }
  // if empty stack
  if(st.empty()){
    nge[i] = -1;
  }
  else{
    nge[i] = st.top();
  }

  st.push(arr[i]);
}


Now the Time and Space Complexity:

T.C. = O(n) for the outer loop and the inner while loop AtMax runs for O(n) => O(2*n)

S.C. = O(n) for the nge[n] and a O(n) for the stack

We can not use the given array as it is not considered good practice to do changes in that.
So we use a new array nge for that.
